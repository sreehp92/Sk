# SK Crackers - Premium Diwali Fireworks Store
Welcome to the official repository for **SK Crackers**, a high-performance, responsive e-commerce web application specialized for direct wholesale and retail Diwali fireworks enquiries via WhatsApp.

## 🚀 Features
* **Interactive Product Catalogue:** Browse certified low-emission green sparklers, flower pots, rockets, and grand aerial celebration packs.
* **Real-time CMS & Admin Panel:** Password-protected professional management console (`#admin`) to manage products, categories, FAQs, and homepage text dynamically.
* **Excel Bulk Import:** Support for Excel (.xlsx) templates to upload inventory instantly.
* **Smart Enquiry Cart & WhatsApp Sync:** Seamless customer checkout flow that packages selected items and details into a clean text enquiry sent directly via WhatsApp.
* **Fully Responsive Design:** Optimized mobile and desktop views with quick navigation and touch-friendly controls.

## 🛠️ Technology Stack
* **Frontend:** HTML5, Tailwind CSS, JavaScript (Vanilla SPA Architecture)
* **Icons & Fonts:** FontAwesome & Google Inter Font
* **Libraries:** SheetJS (XLSX) for bulk uploads, jsPDF for documentation
* **Hosting & Deployment:** Vercel

## 📦 Quick Deployment
1. Clone or download this repository.
2. Ensure the main file is named `index.html`.
3. Import the repository into [Vercel](https://vercel.com) for instant live deployment.
